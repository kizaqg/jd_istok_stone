# Камни истока — автоперековка (Jade Dynasty)

Один файл `JdStones.exe`. Python, Tesseract и .NET ставить не нужно.

## Где взять exe
В репозитории exe не хранится (он собирается автоматически). Скачивайте здесь:
**https://github.com/kizaqg/jd_istok_stone/releases/latest** → раздел **Assets** → `JdStones.exe`.

## Первый запуск
1. Запустите игру, затем `JdStones.exe` (попросит права администратора: без них клики в игру не проходят).
2. **Окно игры…** — выберите `elementclient.exe` (обычно находится само).
3. **Область статов** — поверх игры появится её снимок; выделите строки статов **вместе с колонкой
   «Развитие»**: по ней программа надёжно отличает проценты от чисел, даже если OCR потерял «%».
4. **Кнопка перековки** — кликните по кнопке, которую нужно нажимать.
5. (Необязательно) **Область предупреждения** + **Кнопка подтверждения** — для окна
   «Такие камни весьма редки…».
6. **Проверить распознавание** — покажет, что программа видит и какие статы нашла.
7. Добавьте фильтры и нажмите **F5** (стоп — **F6**).

Цикл: клик по перековке каждые **N мс** (поле «Интервал между кликами», по умолчанию 3500).
Между кликами программа ловит новые статы сразу, как они появились, и проверяет фильтры;
если камень подходит — следующего клика не будет.

Все настройки и фильтры запоминаются (`%APPDATA%\JdStones\settings.json`).
Области хранятся относительно окна игры: окно можно двигать, масштаб Windows не важен.

## Фоновый режим
Позволяет пользоваться компьютером, пока программа крутит камни.
1. Запустите игру **в окне** (в полноэкранном режиме фоновый режим и панель не работают).
2. Нажмите **«Проверить фоновый клик»** — программа сделает одну перековку, не двигая курсор.
   Если статы обновились — включите галочку **«Фоновый режим»**.
3. Окно игры можно закрывать другими окнами. Если свернуть игру во время работы, программа
   развернёт её без активации **за краем экрана** и продолжит крутить; после остановки, находки
   камня или клика по игре на панели задач окно вернётся на место.
4. Пока курсор над окном игры, программа ставит перековку на паузу («жду, пока уберёте мышь»):
   игра берёт настоящее положение курсора, клики иначе промахиваются, а курсор мерцает.

## Панель поверх игры
Галочка **«Панель поверх игры»**: маленькая панель в углу окна игры — старт/стоп, выбор набора,
номер попытки, кнопка ⚙ открывает основное окно. Панель держится над игрой (но не над другими
программами), её можно перетащить мышкой — место запоминается.

## Точность распознавания
* Названия статов читает русский движок Windows, числа — английский (он надёжнее с цифрами,
  точкой и «%»). Если английского распознавания нет, программа подскажет, как его добавить:
  `Add-WindowsCapability -Online -Name "Language.OCR~~~en-US~0.0.1.0"` (PowerShell от администратора).
* «Обработка картинки для распознавания»: «серый с инверсией» или «чёрно-белый (порог)».
  «Проверить распознавание» показывает результат обоих — выберите тот, что читает точнее.
* Тип «в % / числом» берётся из справочника статов; у «Снижен. урона» — по формату числа
  (процент: меньше 1 или 3 знака после точки, например 0.240%; число: 50.70).

## Фильтры
* Группы объединяются через **ИЛИ**, условия внутри группы — через **И**.
* Условие: *стат* · *значение* (`любое` / `в %` / `числом`) · `≥ ≤ =` · *сколько строк*.
  Пример: «Снижен. урона · в % · ≥ · 3» — три строки снижения урона именно в процентах.
* Стат можно выбрать из списка или вписать свой.
* **Наборы**: «Сохранить набор…» запоминает текущие фильтры под названием; выбор набора
  в списке «Набор» сразу подставляет его фильтры.
* Шаблоны в файлах: меню **Файл → Сохранить/Загрузить шаблон** (старые JSON-шаблоны читаются).

## Если программа пишет, что нет русского OCR
Используется встроенное в Windows распознавание текста. На русской Windows оно уже есть.
Иначе: *Параметры → Время и язык → Язык → Добавить язык → Русский*, или в PowerShell от администратора:

```
Add-WindowsCapability -Online -Name "Language.OCR~~~ru-RU~0.0.1.0"
```
